# 0.3.2：保留官方网页错误与请求诊断

0.3.1 在作品 7691911860576128310 的官方分享页显示「抱歉出错了／请尝试在抖音内观看」，但原生界面仍建议等待，关闭后又用“已关闭浏览器”覆盖原因。本版修正这一误导，不宣称恢复媒体提取。

## 改动

- 在同一可见错误容器内识别上述两个独立提示，排除普通打开 App 横幅、隐藏模板和作者文案。新增 WebPlaybackUnavailable，有效目标媒体优先于错误提示。
- 明确错误时暂停自动轮询，保留手动检查及切换页面。每次新加载重置 90 秒自动检查计时；关闭后保留已识别错误。暂停后的手动重查若恢复等待，重新计时。
- 网页拦截、HTTP 错误和网络错误分别计数。仅保存合法主机和固定类别，最多 64 类；不保存 URL 查询、动态路径、Cookie、请求头或响应体。
- 网络报告按会话隔离，重新打开重置，旧回调不能污染新输入或后续成功结果。
- versionName 0.3.2 / versionCode 5，包名与开发证书不变。没有增加权限、SDK 或资源白名单，未实现文件下载。

## 调查结论

用户在普通手机浏览器打开同一链接也失败。桌面受控实验复现错误、0 个视频和 9 次拦截。单独放行两个实际被挡的静态脚本后仍没有视频资源；去除 App 子资源白名单后，62 个请求、0 次 App 策略拦截，仍然报错。因此不能把资源过滤认定为当前故障根因。详细方法及局限见 [V032_RESEARCH.md](V032_RESEARCH.md)。

## 验证边界

构建和离线测试结果在 [v032-validation.json](v032-validation.json)，37 项固定脚本检查在 [browser-script-validation.json](browser-script-validation.json)。覆盖错误分类、诊断脱敏与上限、并发回调、旧会话隔离和成功恢复。真实页面的错误识别已通过桌面 Chrome 验证，脱敏摘要见 [v032-browser-validation.json](v032-browser-validation.json)。

桌面 Chrome 对照及脚本检查不能替代真实 Android WebView 验收。本机没有连接 Android 设备，尚未验证新版在用户手机上显示错误提示的实际效果，也未验证真实媒体提取或文件下载。下一开发阶段仍需先取得可靠的公开媒体样本；下载器尚未开工。
