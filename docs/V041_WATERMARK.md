# 0.4.1 · 优先选择无水印播放源

## 问题与修复

用户确认 0.4.0 手机下载可用，但保存的陀螺视频包含抖音覆盖水印；同一作品在 Douzy 下载后没有该水印。对照作品编号为 `7690145822168750565`。此前推荐器只比较编码兼容性、像素和码率；页面 `play_addr` 实际可以指向官方 `/aweme/v1/playwm/` 带水印分享文件，字段名本身不代表无水印。

本版为准确绑定当前作品的页面状态数据增加公开播放候选。仅处理 HTTPS `aweme.snssdk.com/aweme/v1/playwm/`、单个合法 `video_id` 和已审核参数；补充同一主机的 `/aweme/v1/play/`，保留查询编码、顺序和值。未知参数、签名、凭据、非 HTTPS、不同主机、异常路径、冲突视频 ID、加密媒体均不生成候选。没有修改 CDN 签名，没有生成请求签名或导入登录 Cookie。

原分享地址保留并标记「有水印」。新地址标记「无水印候选源」，不伪称已下载或已逐帧检查。它不继承分享文件的分辨率、编码、码率或大小；同一地址已经由页面明确声明时优先保留页面元数据。推荐顺序为页面标记无水印、公开无水印候选、水印未知、有水印，再比较编码兼容性与已知画质。

失败不会静默改下带水印文件。用户可以重新解析，或主动改选原资源。保存后继续显示 Android 检查到的实际文件参数。作者自己加入的字幕、文字、标志会保留；本版不做裁剪、模糊、画面修补或转码。旧文件不会被自动修改。

## 实际文件证据

2026-10-05 用隔离桌面 Chrome 加载上述作品的公开网页，未导入账号 Cookie。页面准确匹配目标作品，`play_addr` 指向 `aweme.snssdk.com/aweme/v1/playwm/`。

初次对照中原分享文件下载遇到网络错误；同一媒体 ID 的公开 play 地址通过拾影 `VideoDownloader` 下载到 1,194,207 字节 MP4，SHA-256 为 `8f2844ca4947883569d7fedbc6b18c98c4abf34a67148d2d1b1c715b95074ccd`。两条路径均由平台重定向至 HTTPS `v5-hl-mly-ov.zjcdn.com`，未扩展媒体域名列表。

本机离线播放完成：1280 × 720、11.238 秒，有视频与音频解码数据、无播放错误。抽查第 1、4、8 秒画面，未见用户原图中的抖音标志和账号覆盖水印。这是该样本的实测结果，不代表所有视频或网络环境都可用，也不保证逐帧不存在作者自带标志。

新版生产候选规则复测与汇总见 [v041-live-download.json](v041-live-download.json)；编译、单元测试和 lint 见 [v041-validation.json](v041-validation.json)。没有连接 Android 手机，本版新的资源选择策略仍需手机复测。用户此前对 0.4.0 的下载反馈单独保留，不冒充新版真机验收。

## 公开实现参考

核对了 Douzy 的公开固定版本 [desktop-v0.12.1 / core/downloader_base.py](https://github.com/jiji262/douyin-downloader/blob/desktop-v0.12.1/core/downloader_base.py)：它优先选择无水印媒体候选，其部分后备路径使用签名请求。本版独立实现上述经过样本验证的匿名公开路径，不引入该 Python 项目、运行时、账号登录或签名机制。
