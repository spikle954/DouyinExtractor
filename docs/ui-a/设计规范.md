# 拾影 Android UI/UX 改版 · A/B 方案规范

日期：2026-10-09，Asia/Shanghai。基于用户上传的 0.6.0 首页、保存成功截图，以及现有 Compose 界面与下载功能的只读检查。

本轮交付为高保真视觉方向及实施规范，尚未选择最终方案；未修改 Android 源码、提取器、下载服务、持久化或 APK。效果图是生成式设计稿，不是已经运行的 Android 页面；其中的数据、缩略图及图片像素仅作视觉示例。尺寸、色值和行为以本规范为准，后续原生实现须进行真机验收。

## 1. 截图问题与设计决策

| 截图中可见的问题 | 改版决策 |
| --- | --- |
| 大标题、留白、说明、版本号和记录区排在输入前；首屏未露出完整解析操作 | 删除宣传区；顶部小型应用栏后直接显示链接输入和解析按钮；记录排在操作区之后；版本信息进入关于 |
| 保存区域重复出现「新视频保存位置」「已保存到」及说明，阅读成本高 | 下载前保留一个可修改的目录行；成功后只显示本文件的实际目录，不混入下一次下载设置 |
| 每个板块都使用高大的圆角卡片，主要按钮和辅助按钮视觉权重接近 | 保留一个明确主按钮；以排版、分组和分隔线区分内容，减少层层卡片 |
| 深色界面出现紫色背景、主按钮深紫文字，与青绿主色不统一 | 完整指定 Material 色彩角色，包括 onPrimary 和容器色，不只改 primary |
| 成功区域展开长文件名、解释、尺寸、位置与三个大按钮 | 采用短底部弹层，长文件名和完整路径放入文件详情；打开文件夹为主操作，播放和分享为辅助操作 |

现有源码中成功区域是页面内的 Card。本方案提出改为底部弹层，并保留不打断其他任务的轻量完成提示；这是等待确认的交互设计，不是已实施的功能变化。

## 2. 两套方向与共同信息架构

| 维度 | A：Material 3 · 清简 | B：拾影 · 精工青绿 |
| --- | --- | --- |
| 观感 | 柔和、清爽、接近成熟原生工具 | 更冷静、精确，品牌辨识更强 |
| 主色 | 柔和浅青绿 #83D8C6 | 更清晰的青绿 #56DDC3 |
| 形状 | 20dp 内容圆角，28dp 主按钮圆角 | 12dp 内容圆角，14dp 主按钮圆角 |
| 层级 | 以柔和色调表面和文字层级分组 | 以紧凑工作区、必要细边线与对齐分组 |
| 数字排版 | 系统数字样式 | 进度、字节数与速度使用等宽数字；中文仍用系统字体 |
| 保持克制 | 无渐变、装饰阴影或大宣传区 | 无发光、玻璃、科技网格或无关仪表盘 |

两套都只有同样的核心路径：打开/接收分享 → 解析 → 选择资源/分 P → 下载或加入队列 → 保存 → 打开文件夹、播放或分享。顶部提供队列、记录和更多菜单入口，暂不增设底部导航栏。队列有任务时显示轻量数量；无任务时不显示伪造的数字。

更多菜单提供现有隐私说明、诊断及版本信息。输入区的「解析选项」展开后保留自动网页提取开关和必要的流量说明，不改变原有开关状态、默认行为及 WebView 限制。

视觉稿各自展示：首页、解析结果、下载队列、记录搜索、保存成功。解析结果可作为当前首页的独立视觉状态，保留同一个 ViewModel；不以新增导航层为由重写业务。

## 3. 色彩角色

全部为不透明 sRGB HEX。产品色固定映射到完整 Material 色彩角色，不从系统壁纸随机获取强调色。本轮只设计深色界面，不增加主题设置功能。

| 角色 / 用途 | A | B |
| --- | --- | --- |
| background / surface：页面基础 | #111817 | #0C1315 |
| surfaceContainer：分组内容、记录 | #1A2421 | #172225 |
| surfaceContainerHigh：弹层、菜单 | #25312C | #1E2D30 |
| primary：主操作、选中、进度 | #83D8C6 | #56DDC3 |
| onPrimary：主按钮文字与图标 | #00382F | #062D26 |
| primaryContainer：必要的强调底色 | #124B40 | #154B42 |
| onPrimaryContainer | #C0F3E5 | #BAF2E4 |
| onSurface：主要文字 | #E1ECE7 | #F0F7F4 |
| onSurfaceVariant：说明、次级信息 | #B6C7BF | #ADBEB8 |
| outline：可交互边界、未选单选框 | #82968B | #698A82 |
| outlineVariant：装饰分隔线 | #34443C | #263B36 |
| error：错误文字与图标 | #FFB4AB | #FFB4AB |
| errorContainer / onErrorContainer | #59332F / #FFDAD5 | #59332F / #FFDAD5 |
| scrim：模态背景遮罩 | #000000，40% | #000000，40% |

secondary / tertiary、反色与表面层级等角色在 design-tokens.json 中使用同一青绿和中性色系指定，避免默认紫色进入按钮或保存容器；本次交互不依赖第三强调色。禁用背景为 onSurface 12% 覆盖 surface，禁用文字为 onSurface 38%，同时保留「尚无可下载资源」等原因文案。禁用不作为唯一的错误提示。

对比度按 sRGB 相对亮度计算：A 的主要文字/内容背景 13.16:1、次级文字/弹层 7.66:1、主按钮文字/主色 7.84:1；B 分别 14.95:1、7.35:1、8.88:1。完整结果见 contrast-validation.json；这是指定色值计算，不等于生成图片或实际 App 已通过无障碍测试。

普通文字目标至少 4.5:1，关键控件边界/状态至少 3:1。装饰分隔线允许更低对比，但不能作为识别控件的唯一方式。参照 [Android 可访问性指南](https://developer.android.com/guide/topics/ui/accessibility/apps)、[WCAG 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum) 和 [非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

## 4. 字体与间距

字体使用 Android 系统中文无衬线及其字体回退，不将文字烘焙为图片，不要求用户下载字体。字号用 sp，布局尺寸用 dp；以下为本产品选择的尺寸，不声称每项都等于 Material 官方默认值。

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 应用栏「拾影」 | A 20/28sp；B 22/28sp | 600 / 500 |
| 页面标题、首页任务标题 | 22/28sp | 600 |
| 成功标题、分组标题 | 18/24sp | 600 |
| 输入正文、记录标题 | 16/24sp | 400 / 500 |
| 按钮文字 | 14/20sp | 600 |
| 次级正文、目录、作者 | 14/20sp | 400 |
| 日期、来源标签等辅助信息 | 12/18sp | 400 |
| 进度百分比 | 20/28sp | 500；B 使用等宽数字 |
| 速度、字节数 | 14/20sp | 400；B 使用等宽数字 |

不使用 10sp 灰字承载操作或错误。字号随系统设置缩放，不能为了守住卡片高度把字体缩回去。长标题默认最多两行并提供详情读取完整文本；完整文件名不得成为默认主标题。

间距基于 4dp 网格：4（图标与文字微调）、8（相关行）、12（组件间）、16（分组内边距）、24（独立区块）。A 屏幕侧边距 16dp、区块间距 16–24dp；B 侧边距 20dp、区块间距 20dp。标题与副标题 4–8dp，缩略图与文字 12dp，操作按钮之间 8–12dp。

## 5. 组件尺寸与各页布局

| 组件 | A | B | 共同规则 |
| --- | --- | --- | --- |
| 顶部应用栏 | 最小 56dp | 最小 56dp | 不含系统状态栏；图标可见尺寸 24dp，点击区域至少 48×48dp |
| 主按钮 | 最小高 52dp，圆角 28dp | 最小高 52dp，圆角 14dp | 一个主动作；放大字体时自适应增高 |
| 辅助/文字按钮 | 最小高 48dp | 最小高 48dp | 不将紧凑外观变成小点击目标 |
| 多行输入 | 最小高 136dp，圆角 20dp | 最小高 136dp，圆角 12dp | 可见 3 行左右，长分享可编辑/滚动；清除触区 48dp |
| 搜索框 | 最小高 56dp，圆角 16dp | 最小高 56dp，圆角 12dp | 搜索/清空图标，查询为空不改变记录排序 |
| 首页记录分组 | 圆角 20dp；行最小 88dp | 圆角 12dp；行最小 80dp | 行随内容和字体增高；同一表面内分隔，不逐项堆叠大卡片 |
| 首页缩略图 | 48×64dp，圆角 8dp | 40×56dp，圆角 6dp | 保持画面比例，通过裁切适配；失败显示视频图标 |
| 解析结果缩略图 | 80×106dp，圆角 8dp | 80×106dp，圆角 6dp | 可为横屏视频改用自然比例，不拉伸 |
| 资源/分 P 选择行 | 最小 64dp | 最小 64dp | 单选语义及选中图标；整行可点击 |
| 目录行 | 最小 56dp | 最小 56dp | 一行短位置 + 修改入口，必要时增加第二行 |
| 当前任务进度条 | 4dp | 4dp | 有总大小才显示百分比；未知大小不伪造百分比 |
| 成功底部弹层 | 顶部圆角 28dp | 顶部圆角 24dp | 标准字级目标 340–370dp + 底部系统 inset；不是硬上限 |
| 成功缩略图 | 56×72dp | 56×72dp | 用小图及文件信息，不使用大庆祝徽章 |
| 菜单、对话框 | 16 / 28dp 圆角 | 12 / 24dp 圆角 | 菜单条目触区最小 48dp，长说明可滚动 |

首页顺序：应用栏 → 简短任务标题及支持平台 → 输入 → 粘贴/解析 → 可展开解析选项 → 有任务时的紧凑队列摘要 → 最近保存。标准 390dp 宽度下，主操作在上半屏；360dp 宽度、常规字体时，无需先滑过记录才能解析。无历史时只显示「暂无保存记录」的轻量状态，无任务时不保留队列占位卡。

记录管理默认按时间排列，首页最多展示两条，点击「全部记录」进入搜索列表。列表标题来自记录原始标题，缺少标题时才使用短文件名；完整路径、完整文件名、作品编号、平台/分 P 等通过「文件详情」查看。最近 50 条限制和多关键词搜索逻辑保持不变。

当前历史数据不为每条记录持久化封面和实际尺寸。实施时，缩略图只能从已有可访问的本机视频 URI 按需获取，使用缓存且离开列表后取消无用加载；不为装饰再访问平台或扫描整个相册。旧记录缺少作者、质量、缩略图时不虚构；历史里只显示现有字段，资源标注不得伪称为已验证文件参数。成功反馈可以使用本次保存检查得到的实际尺寸和时长。

## 6. 保存成功的具体收敛

标准弹层只包含：小型完成图标与「已保存到手机」；最多两行标题；一行文件信息（例如 14.1 MB · 720×1280 · 1:28）；一行当前文件实际位置；主按钮「打开文件夹」；辅助动作「播放视频」「分享文件」。路径只出现一次；全名和其他解释转入文件详情。

底部弹层可关闭，关闭不删除文件。后台或队列中的任务完成时不逐项抢占界面、不自动切页。如果用户正在编辑/解析另一个作品，仅更新队列和记录，并显示可关闭的轻量「已保存」提示及「查看」入口；前台查看当前作品的下载结果时才展示成功弹层。同一个任务完成只提示一次。

当前截图中的既有目录是「下载 / Download」，设计稿据此展示该例，不默认迁移到 Movies/拾影。新装默认目录、自选 SAF 目录、旧路径与每个任务固定目录的规则全部保留。文件夹跳转及系统选择器回退继续调用现有方法。

## 7. 状态与反馈

| 状态 | 界面变化 | 保留的行为 |
| --- | --- | --- |
| 空输入 | 输入提示「粘贴链接或完整分享文案」；解析不可执行，粘贴可用 | 不在后台自动读剪贴板 |
| 已输入 | 单一主按钮「解析链接」 | 不自动下载 |
| 输入聚焦 | 2dp primary 边框、可读标签；内容避让输入法 | 多行粘贴、光标编辑、清除可用 |
| 普通解析中 | 输入附近显示真实阶段；主按钮改为「取消解析」并保留取消能力 | 调用原解析取消，不伪造可计算进度 |
| 网页辅助提取 | 保留可见原生 WebView 窗口、当前作品限制、手动验证、桌面入口及关闭操作 | 不改成不可见绕过；流量提示与开关保留 |
| 解析成功 | 展示作品和可选资源；一个「下载视频」或「加入下载队列」主按钮 | 分 P 切换、原资源、无水印候选、未知字段按真实数据展示 |
| 链接错误 | 输入旁错误图标+短文字，保留输入及修正动作 | 不把 HTTP 200 或仅编号识别当提取成功 |
| 无媒体/网络错误 | 独立错误状态，给出原有网页继续提取/重试/诊断入口 | 不新增无限重试，不隐去关键原因 |
| 按下/聚焦 | primary 状态层 12% + 原生 ripple；保持文字可读 | 无弹跳、扫光或卡片变形；遵循系统减少动画设置 |
| 重复下载 | 紧凑对话框：标题、旧文件位置、播放已有/仍然下载/取消 | 文件不存在时正常重下；无法确认时诚实提示；B 站按分 P 判断 |
| 已在队列 | 轻量说明「这个视频已在队列中」+ 查看队列入口 | 不重复加入同一作品/分 P；不同分 P 可分别添加 |
| 排队 | 仅显示顺序、短标题、自己的目标位置和移除操作 | 最多 20 个；资源与目录固定；不是多线程下载 |
| 传输/校验/保存 | 显示真实阶段及适用的进度，取消指向当前任务 | 校验或大小未知时不显示虚假 100% |
| 取消当前 | 清晰表示当前取消，后续可执行任务继续 | 不清空队列；不加入暂停/续传按钮 |
| 失败/进程中断 | 保留「重新解析」和移除入口，失效原因短句显示 | 重开后需新地址，不自动续传；不更改恢复元数据 |
| 搜索无结果 | 「没有找到相关记录」+ 清除搜索 | 不制造推荐内容，不自动联网查询 |
| 文件已删除/授权失效 | 说明原因，保留重新解析或选择目录入口 | 不假装旧文件仍可播放；不申请全部文件权限 |

## 8. 真机适配与可访问性

基准按 390×844dp 的纵向窗口思考；生成稿只绘制应用内容，没有模拟 OS 状态栏和导航条。原生布局必须依据实际 WindowInsets，不能硬编码某款手机 24dp 状态栏或 34dp 导航栏。页面背景可延伸，交互内容避让状态栏、手势导航和三键导航区。

键盘打开时优先保留输入和解析动作；首屏不让最近记录把操作挤到屏外。采用可滚动内容与 IME inset 避让，聚焦输入后可移动到可见位置；输入和按钮始终有滚动可达路径。返回键先关闭输入法，再遵循当前弹层/页面返回顺序；不影响后台下载。输入法样式由用户键盘决定，不设计自定义键盘。

字体 100%、130%、150%、200% 都作为后续验收范围。文字和按钮采用最小高度而非固定高度；大字号时按钮增高，成功弹层可增长或滚动。两列辅助按钮在宽度不足时切为纵向；标题和元数据允许换行。紧凑记录不意味着牺牲可点击区域。

触区至少 48×48dp，与 [Android 可访问性指南](https://developer.android.com/guide/topics/ui/accessibility/apps) 一致。TalkBack 读序为输入标签 → 文案 → 解析 → 队列摘要 → 记录；图标提供目的明确的标签，例如「打开老师送学生回家的保存文件夹」，避免重复的「更多」而不说明对象。资源行暴露单选语义和选中状态，错误同时使用文字/图标，状态不只靠颜色。弹层打开与关闭管理焦点，进度播报节流，不每秒打断阅读。

后续验证窗口至少覆盖 360×800、390×844、412×915dp，短屏/横屏、软键盘显示、三键与手势导航、大字级、长中文/英文文件名、长目录、已有旧记录与无数据。这些是设计验收条件，尚未进行布局运行或真机测试。

## 9. 确认后实施边界

| 可优先调整的展示层 | 必须保留的现有能力 |
| --- | --- |
| 完整 Material 色彩角色、字级、形状及间距 | 现有提取器、网址校验、匿名请求及无水印候选规则 |
| 输入优先的 Compose 布局及条件展开 | MainViewModel 分享接收、请求取消、分 P、诊断和 WebView 生命周期 |
| 队列摘要、紧凑列表和原生弹层 | DownloadRuntime / DownloadQueueWorker 的串行交接、取消与恢复逻辑 |
| 保存反馈、记录菜单、同数据源的详情呈现 | VideoStorage 的校验、MediaStore/SAF、固定目录、播放/分享授权 |
| 可访问性语义及按需本机缩略图 | SavedDownloadHistory 搜索、重复文件检查和旧记录兼容 |

先只替换表现层并继续使用现有状态流、回调和持久化结构；避免为效果图临时加入新的网络服务、权限、账号体系或独立下载引擎。正式实施后运行既有 313 项回归及编译/lint，再补真机键盘、导航、字体与连续下载验收。当前本轮不执行任何实现或发布。

## 10. 交付文件

两套总览各为一个统一视觉方向，包含五个主要页面/状态。全尺寸 PNG 可用于选择方向；design-tokens.json 是待选方案的设计值，不能直接当作已上线配置。contrast-validation.json 保存指定色值的计算结果；生成提示词.md 记录使用内置 Image Gen 制作视觉稿的设计约束。

本轮先确认 A 或 B；若希望组合两者的部分元素，应先出一版明确的合并设计稿再实施，不在选定前混合改源码。
