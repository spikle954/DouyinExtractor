# 拾影使用说明（0.8.5）

覆盖安装 shiying-0.8.5-debug.apk，无需卸载。此前安装 development-signed release 的用户使用对应新版；unsigned 包不能直接安装。

## 快手（含极速版）与小红书

粘贴一条完整视频分享文案或官方短链，点击解析；也可在原 App 的系统分享菜单选择拾影。提取后选择资源，点击底部下载按钮。新平台使用原保存目录、后台队列、记录搜索、重复提醒、播放、文件夹和分享操作。

小红书请保留原分享链接中的访问参数，不要手工改成无参数的规范链接。参数只用于当前提取，不保存在队列/记录或诊断中。应用重启或地址失效后，从小红书重新复制同条视频的分享链接，解析后再加入队列；待办的重新解析入口会提示你重新分享。

资源列表可能包含同画质的备用线路和不同编码，数量不等于画质档位数。画质、水印、时长和尺寸以实际文件为准；不处理作者自带标志。只支持普通公开视频；图文、图集、直播、付费/私密或登录限制、分离/分段/加密资源暂不支持。

## 哔哩哔哩

粘贴完整分享文案、b23.tv 短链、BV/AV 视频链接，或纯 BV/av 编号，点击解析。也可从 B 站系统分享菜单选择拾影。

提取后显示标题、封面、时长与实际返回画质。保持推荐线路并下载；不同线路是同一画质的备用地址。若有多分 P，点「选择分 P」切换，等待新一集提取完成后再下载。带 ?p=2 的链接默认选择第二集，一次只保存当前集。

结果页的下载按钮固定在底部；上方作品、资源和保存目录仍可滚动。所选资源与保存位置使用原规则，点击下载仍会检查重复记录。

首版不登录账号，不承诺全部画质可用；付费、会员、登录、番剧、直播、互动、音视频分离或分段资源暂不支持。失败时会明确提示。不会下载一条无声视频轨并宣称完整成功。

## 抖音

原有分享、自动网页提取及无水印候选优先逻辑保留。可展开首页「解析选项」关闭自动网页提取，仅在需要时主动打开。候选源不可用时可重新解析或主动选择原资源；作者自带文字和标志仍保留。

## 保存与重试

首次推荐保存到 `Movies/拾影`（Android 10+），或选择本机文件夹；Android 8/9 使用系统文件夹选择器。自选目录继续沿用。允许通知后可在后台看进度，完成通知显示保存位置；拒绝通知仍可在 App 查看。

前台当前任务完成后，底部弹层展示文件摘要和「已保存到」位置，可打开文件夹、播放或分享。排队任务完成不打断新的解析，可通过轻提示或顶部下载记录查找。默认文件可在「文件管理 → 手机存储 → Movies → 拾影」找到；系统相册也可查找「拾影」相册，部分手机显示可能稍有延迟。文件管理器不支持直接跳转时，会打开系统视频文件选择界面，选择视频即可播放。

首页「最近保存」显示两条摘要，顶部「下载记录」保留最近 50 条记录，关闭 App 或开始下一次下载后仍可查找。在列表顶部搜索标题、作者、视频编号、平台、分 P、画质或保存位置，多个关键词用空格分开。旧版记录也可按文件名和位置查找。记录保存每个文件自己的位置，不随之后的目录设置变化。实际分辨率和时长以保存后的检查结果为准。

记录封面来自对应的本地视频。Android 8.1+ 在文件夹未提供预览时尝试生成一帧小图；首次显示可能稍有等待。无法解码、文件不可访问或 Android 8.0 时显示视频图标；图标不代表文件丢失，可点播放确认。

旧版默认下载在「文件管理 → 手机存储 → Download → DouyinExtractor」，升级不会移动旧文件。可恢复旧版最后一次成功下载记录；更早的旧视频请到旧目录查找。文件已移动、删除或目录权限已撤销时，旧记录可能无法打开。下载失败或地址过期时点「重新解析这个视频」，B 站会保留原分 P。当前重试从头下载，暂不支持暂停和断点续传。

取消/失败会尝试清理未完成文件；空间不足、目录权限被撤销时，请腾出空间或重选目录。单个文件最大 2 GB，临时下载与保存阶段需要约两份文件空间。系统强停后需重新解析，不会自动续传。

## 下载队列

当前视频下载时，继续粘贴或分享另一个链接，提取完成后点击「加入下载队列」。最多 20 个任务，按顺序逐个下载；每个任务记住添加时选定的资源和保存目录。B 站要添加另一分 P 时，先切换到该集并等待提取完成，再加入队列。

顶部下载图标和首页队列摘要可查看当前任务及待办；大字体时使用顶部更多菜单。「取消当前下载」只取消正在传输的任务，后续任务继续；移除单个待办或「清空待办」不删除已保存文件。相同作品和分 P 正在下载或等待时不会重复加入。

某个任务失败后会保留「重新解析」入口，其余可执行任务继续。点重新解析，提取完成后再次添加，可替换原待办项。媒体地址可能过期，因此应用被系统结束后会保留任务信息，但重开时需分别重新解析，不会在后台自动恢复。进程仍在且有可执行待办时，可点击「继续下载队列」。

## 重复下载提醒

下载前会检查最近 50 条保存记录及对应文件。已有可访问的同一作品时，可选择「播放已有视频」或「仍然下载」。B 站不同分 P 分别判断；同一分 P 的不同画质仍会提醒，但允许继续。已有文件被删除时可以直接重新下载。

目录权限变化或文件提供程序暂不可用时，应用会显示无法确认文件是否可访问，仍可继续下载。旧版记录尽可能从文件名判断作品；修改过文件名或超出最近 50 条的文件可能无法识别重复。

## 本版手机测试

1. 添加两个不同视频，确认第二条等待，第一条完成后自动下载第二条。再试取消第一条，确认第二条继续；也可切到后台查看通知。
2. 在「下载记录」按标题或作者搜索，确认可播放、打开文件夹；重开 App 后仍能搜索旧记录。
3. 再下载同一作品，确认出现重复提醒，分别试播放已有文件和「仍然下载」。删除已有副本后重试，确认不再误报。B 站不同分 P 应能分别加入队列。
4. 改目录后添加另一任务，确认各任务使用添加时的目录；队列尚未完成时手动强停再重开，确认待办显示需要重新解析，且不自动下载。

失败时复制「查看诊断信息」内容；发送前检查分享文案。诊断不包含媒体签名直链、Cookie 或保存目录 URI。

## 0.8.0 手机复测

1. 分别粘贴你提供的两条分享文案，检查标题、作者、封面、资源及平台名称；再试从快手/小红书直接系统分享到拾影。
2. 各下载一次，确认位置正确、文件能播放且有声音；在记录里按“快手”或“小红书”搜索。
3. 一个下载时添加另一个到队列；再下载相同作品，确认重复提醒。检查文件夹、播放及分享。
4. 若小红书重试提示无法访问，请重新复制完整分享链接；仍失败时从顶部更多菜单复制诊断，发送前检查分享文案。

## 快手提取失败与 0.8.2 复测

请覆盖安装新版，再粘贴原分享文案解析。0.8.2 在电脑版页面缺少目标资源时自动尝试一次官方手机分享入口。它不会保证平台每次都提供公开视频数据。平台要求登录、拒绝访问、作品不存在、HTTPS 安全连接失败或跳到其他作品时不会继续换入口。

失败后点顶部「⋮ → 查看诊断信息 → 复制诊断」。新版会区分域名解析、HTTPS 连接、超时、连接中断、页面大小及状态解析；记录目标状态和 MP4 候选数量，不记录异常原文、页面内容、媒体直链或访问参数。看到短链定位 HTTP 响应数为 0 不等于链接文案不支持，请同时查看失败说明。

诊断末尾的独立下载任务可能是之前的视频。此前任务 COMPLETE 不代表当前链接提取成功。当前真机失败仍待新版诊断确认；本机核心实测记录见 [V082_PUBLIC_PAGES.md](V082_PUBLIC_PAGES.md)。

## 0.8.4 快手本机网页提取

普通快手与快手极速版仍共用作品编号和下载逻辑。部分分享在普通请求中只有网站外壳，手机浏览器却能播放时，新版会按首页「解析选项」设置自动打开当前作品的可见官方网页。关闭自动网页后，可以点击「用网页继续提取」。网页加载和播放会产生流量。

等待网页加载；必要时点击网页中的播放按钮。若出现正常验证，在可见页面中手动完成后点击「检查视频资源」；不需要导入 Cookie。取得目标作品信息后自动返回解析结果，再点击下载。若仍未找到，可尝试分享页入口一次或关闭并复制诊断。页面要求登录的内容不支持，应用会结束此次网页提取。

本次复测重点是第二条“王刚鉴宝失手”极速版分享，作品编号 3xie2x2ahb2weu9：粘贴完整文案，确认普通解析没有媒体时能进入网页，提取后下载并有声播放。再试上一条“桃子邪修怎么记”及普通快手。关闭自动开关再试，确认只有主动点网页按钮才打开。

开发机已用实际网页快照、生产解析器和下载器取得第二条完整 MP4，尚未在 Android WebView 中确认同样结果；不能据此承诺手机修复完成。若仍失败，请从顶部「⋮ → 查看诊断信息 → 复制诊断」提供新版报告。无需卸载，原保存目录、队列和记录保留。实现及验证范围见 [V084_KUAISHOU_BROWSER.md](V084_KUAISHOU_BROWSER.md)。

## 0.8.5 快手验证后提取

网页辅助现在优先进入当前作品的官方分享入口，无需先在视频页验证再手动切换。遇到快手安全验证，请在网页中正常手动完成；识别到验证界面时，会留出最多 10 分钟连续验证等待，验证界面消失后再继续等待作品数据。页面正常加载仍有 90 秒上限，不会无限重试。平台是否要求验证由快手决定。

播放器已能播放时，新版会补查绑定当前作品的动态数据，取得资源后自动返回；也可点击「检查视频资源」。页面显示不完整时，可点「缩小网页」或双指缩放，手机实际缩放和布局仍需复测。视频页保留为手动备用入口，切换入口不会退出当前临时网页会话。

请先重试你提供的“刘宪华北京演唱会小提琴被调包了”分享，完成验证后检查是否能返回资源列表、下载并有声播放。如果某条资源下载失败，可选同一列表的另一条资源重试；不同 CDN 线路可能有不同可用性，应用仍拒绝不受支持的跳转。仍无法提取时复制新版完整诊断。无需卸载，原目录、下载队列和记录沿用。
